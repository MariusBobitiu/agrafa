# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Agrafa. Older
versions may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Email security@agrafa.co with:

- a description of the vulnerability and its potential impact;
- the affected version or commit;
- steps to reproduce or a proof of concept; and
- any suggested remediation, if available.

Please avoid including credentials, tokens, or other sensitive data that is not
necessary to reproduce the issue.

We aim to acknowledge reports within three business days and will coordinate
remediation and disclosure with the reporter. Please allow reasonable time for
a fix before publicly disclosing the vulnerability.
